# 🎬 CineFlix

Aplicação web de catálogo de filmes desenvolvida com **JavaScript puro, HTML5 e CSS3**.

O projeto tem como objetivo praticar conceitos fundamentais do desenvolvimento Front-End, como manipulação do DOM, eventos, arrays, filtros, armazenamento local e criação de interfaces dinâmicas.

## 📌 Sobre o projeto

O CineFlix é uma aplicação que permite ao usuário explorar um catálogo de filmes, realizar pesquisas, filtrar por categorias e salvar seus filmes favoritos.

A aplicação foi desenvolvida sem o uso de frameworks, utilizando apenas JavaScript puro para reforçar a lógica de programação e o entendimento do funcionamento do navegador.

---

## ✨ Funcionalidades

✅ Listagem dinâmica de filmes  
✅ Pesquisa de filmes por título  
✅ Filtros por gênero  
✅ Sistema de favoritos  
✅ Persistência dos favoritos utilizando LocalStorage  
✅ Mensagens de interação ao favoritar/desfavoritar filmes  
✅ Renderização dinâmica dos cards  
✅ Interface responsiva para diferentes dispositivos
